# PROBAFOOT

Application premium de pronostics football avec moteur probabiliste, analyse de forme, performances des titulaires, historique des confrontations et gestion d’abonnements VIP.

## Fonctionnalités
- Moteur probabiliste 1 - N - 2 avec 7 curseurs en temps réel
- Analyse des 3 derniers matchs
- Analyse des titulaires et performances clés
- Analyse des affrontements directs
- Contexte tactique, enjeu immédiat et objectif de saison
- Calculateur de gains / bénéfices
- Abonnements VIP fixes : 35€, 130€, 1520€
- Authentification utilisateur simulée
- Aucune zone d’admin ni publication de pronostics côté admin

## Stack
- Next.js 14
- React
- TypeScript

## Démarrage
```bash
npm install
npm run dev
```

Puis ouvrez : http://localhost:3000
